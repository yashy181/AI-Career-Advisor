# AI Career Advisor

AI-powered Career Advisor built using React and OpenRouter API. This application provides personalized career guidance, skill recommendations, learning roadmaps, and technology suggestions using Artificial Intelligence.

## Features

* AI Career Guidance
* Personalized Learning Roadmap
* Skill Recommendation System
* Technology Suggestions
* Salary & Career Insights
* Modern Responsive UI
* Real-time AI Responses

## Tech Stack

* React.js
* JavaScript
* Axios
* OpenRouter API
* CSS



```bash id="m7n1vk"

```


